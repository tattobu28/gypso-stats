gypso-stats

gypso-stats は、GYPSO RECORDS の運営者が自分のYouTubeチャンネルの数字を記録するための個人用ツールです。一般には提供していません。

プライバシーポリシー

取得する情報

YouTube Data API と YouTube Analytics API を読み取り専用の権限で使い、認証したチャンネルの動画情報、再生数、高評価数、コメント数、登録者数、視聴維持率、流入元の集計値を取得します。動画やチャンネルの情報を変更することはありません。

利用目的

取得した情報は、運営者が自分のチャンネルの動向を記録し、分析するためだけに使います。

保存と共有

取得した情報と認証情報は運営者のパソコンにのみ保存します。第三者への販売や提供はしません。

アクセス権の取り消し

付与したアクセス権は、Googleアカウントの権限設定からいつでも取り消せます。

関連するポリシー

このツールは YouTube API Services を使用しています。Googleプライバシーポリシーもご確認ください。
